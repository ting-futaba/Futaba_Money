# 雙葉帳簿

離線優先的個人 Android 帳本，支援 Android 8.0 以上。可管理日常收支、拆分付款、固定排程、分類預算、外幣帳戶及股票持倉。

## 最新版本 v0.7.19

總覽月份與統計同列；一般帳戶直接顯示當月明細，月統計另列，股票入口維持專屬畫面。加入整體持倉損益及加權比例，縮高並美化記帳鍵盤。A53、大字及複雜表單仍待驗。

- [下載 v0.7.19 APK](https://github.com/ting-futaba/Futaba_Money/releases/tag/v0.7.19)
- 已安裝的使用者可從 App 內更新。GitHub 與已設定的 Tailscale 更新站提供同一份 APK。
- 升級前可先匯出加密備份，再覆蓋安裝新版以保留本機帳本。

自動報價以來源實際提供的盤後資料為準，部分美股需手動輸入。v0.7.19 已通過自動測試與 Android 建置，A53 實機及換機還原驗收仍待完成。

## 資料與隱私

帳本保存在裝置上。分享 APK 不會附帶帳本。匯出的加密備份與 CSV 含有個人資料，請自行保管。清除 App 資料或解除安裝前，請先備份。
