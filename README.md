# 雙葉帳簿

離線優先的個人 Android 帳本，支援 Android 8.0 以上。管理日常收支、拆分付款、固定排程、分類預算、外幣帳戶及股票持倉。

## 功能

- 收入、支出、轉帳、分類拆分、成員、日曆與交易明細。
- 一般帳戶整列開當月明細，月收支及餘額統計在三點選單；投資帳戶開持股畫面。
- 股票純持股，買賣及現金股利入扣交割戶。FIFO成本、已實現與未實現損益分開，持倉總損益率依剩餘成本加權。
- 股票買賣本金不列生活支出，僅總覽收支結餘納入交割現金流，現金股利計算一次。
- 外幣原幣餘額與台幣估值、手動匯率與股價、加密備份與CSV。
- 分類預算、獨立訂閱頁、固定交易及提醒。排程只記帳，背景只提醒，開啟解鎖後處理當日期數，漏期需確認。

## 安裝與更新

已安裝的使用者可從 App 更新中心更新。GitHub 與自行設定的 Tailscale 更新站提供同一份APK。升級前另存加密備份，覆蓋安裝可保留本機帳本。

## 行情及驗證限制

台股使用TWSE／TPEx、估值匯率使用TAIFEX。美股以銀行公開清單涵蓋範圍為準，不保證任意代碼自動取價，未涵蓋時可手動輸入。保留資料實際日期，下載成功不代表已有新交易日價格。交易交割日自動估算內建2025至2027年例行市場交割日曆，缺少適用日期時提示無法推算。

本版通過155項核心測試、Chrome正常入口回歸、Android lint與建置、41項APK程式資源稽核。手機360／384／412寬、橫向、日夜及放大字級取樣不等於完整實機矩陣；A53原生鎖定、通知、觸控、系統大字、下載安裝與換機還原仍待實機驗收。

## 資料與隱私

帳本保存在裝置上。APK不含個人帳戶、交易、預算或私人附件。加密備份與CSV含個人資料，請自行保管。移除App或清除資料前先備份；金額遮罩及App鎖不等於資料庫加密。
