# 雙葉帳簿 Futaba Ledger

以 Android 手機為主的離線個人帳簿。安裝檔不含使用者的帳戶、交易或預算資料。

## 最新版本：v0.6.2

- 訂閱年度估算另起一行，固定收支與轉帳入口集中於更多。
- 日曆顯示固定排程（預），與實際交易分開，不影響帳戶餘額、預算已花金額或正式統計。

- 趨勢管理使用綠色文字按鈕，最近紀錄入口精簡。
- 圓餅選取提示只保留名稱、比例；訂閱資訊與操作分層排列。
- 訂閱連結沿用有效綁定帳戶，舊資料可使用分類預設帳戶，失效綁定要求重新選擇。

## 功能與操作

收入、支出、轉帳、付款內分類拆分、代墊及收回、成員、日曆及列表、帳戶分組與月報、主子分類、分類預算、固定排程及訂閱、日夜模式、圖形與生物辨識安全鎖、加密備份及CSV匯出。

完整統計可從總覽捷徑或更多進入。中央圓形加號短按記帳、上滑開啟分類輪盤；設定位於記帳與排程內。輪盤選取只帶入表單，不會直接入帳。

預算的月額度是狀態標示基準；跨月模式以年度剩餘除以含當月的剩餘月份判斷進度警告，超月不一定需要警告。警告不阻止正常記帳。未設定額度不顯示假使用率。

固定排程只產生帳簿紀錄，不會向銀行扣款。開啟或返回App處理當日期數，錯過期數需確認。安全鎖並非資料庫加密；帳戶金額隱藏同步遮住帳戶及總覽資產；本月支出、結餘、交易及編輯仍可查看金額。

## 安裝與更新

從 [Releases](https://github.com/ting-futaba/Futaba_Money/releases/latest) 下載APK，或使用App更新中心。支援GitHub及自行設定的私人更新站。升級前另存加密備份，以新版覆蓋安裝，不必移除舊版。備份與簽署金鑰請勿公開分享。

## 驗證與限制

v0.6.2 通過104項自動測試、Android建置與lint，並檢查APK資源及資料混入。手機尺寸瀏覽器驗證不等同A53實機驗收；原生通知、重啟／時區／省電、生物辨識、系統安裝器及實際觸控手感仍需實機確認。圖表以既有新台幣帳務為基準，負值退款在清單明示，圓餅比例只依正值計算。
