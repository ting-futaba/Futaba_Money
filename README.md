# 雙葉帳簿

離線優先的 Android 個人記帳工具，支援 Android 8.0 以上。

## 最新版本：v0.4.2

[下載最新版 APK 與更新說明](https://github.com/ting-futaba/Futaba_Money/releases/latest)

本版依日曆查帳習慣精簡介面，保留 v0.4 的帳戶月報及查帳功能：

- 主導覽不再支援左右滑動換頁；子功能切月與分頁手勢保留。
- 交易標題右側使用統一 📅 今日入口；選日改為圓角正方形。
- 日曆不重複日期、不顯示搜尋篩選；列表條件不影響日曆資料。
- 當日收支與轉帳分組呈現，轉帳不列入收支合計。

- 交易頁預設日曆，緊湊日期格及按日分組列表，搜尋篩選僅在列表顯示。
- 日期／月份可快速跳年，按確定才套用，取消保留原值；快捷鍵統一為「今日」。
- 短頁底部空白支援左右滑動，移除多餘導引文字，統一彈窗內距。
- 畫面隱私確認改為 App 自訂原生內容，驗證仍受安全鎖保護。

- 日曆／列表切換、選日查帳、月份切換與當日收支摘要。
- 帳戶月報：期初、收入、支出、轉入轉出、退款、校正與期末餘額。
- 統一月份、日期與一般選項彈窗；使用「今日」快捷鍵回到當月或當日。
- 支援彈窗外點關閉、驗證自動提示生物辨識、截圖狀態顯示與緊湊預算操作。
- 預算刪除保留確認，取消刪除復原及其提示。

## 既有功能

收入／支出／轉帳、付款內分類拆分、退款、帳戶分組、主子分類、多年度分類預算、固定排程與訂閱、日夜間模式、圖形與生物辨識安全鎖、加密備份與 CSV 匯出，以及 GitHub／私人更新站雙來源更新。

固定排程只產生帳簿紀錄，不會向銀行扣款。開啟或返回 App 時處理當日期數，錯過期數需確認。安全鎖不是資料庫加密。

## 安裝與更新

從 Releases 下載 APK，或使用 App 更新中心。升級前建議另存加密備份，使用新版覆蓋安裝，不要先移除舊版。安裝檔不包含使用者帳本；備份請自行妥善保存，不要公開上傳。

## 驗證與限制

v0.4.2 通過 78 項自動測試、Android 編譯與 lint，包含月報對帳、退款、作廢交易及日曆邊界。手機尺寸瀏覽器預覽不等同 Android 實機驗收；原生指紋、安裝器與觸控手感仍需進一步實機確認。本版仍為持續開發中的測試版本。
