# 雙葉帳簿 Futaba Ledger

Android離線個人帳簿，安裝檔不含個人帳戶、交易或預算資料。

## 最新版本：v0.7.8

- 投資帳戶設定純持股與交割戶，買賣及現金股利由交割戶入扣帳。舊帳戶轉換前需確認，舊現金另存待核對，保留歷史與淨資產。
- 帳戶整列可點入，三點選單獨立；期初／配股／分割改顯示成本及股數資訊。
- 修正Android銀行手機版302與收盤價解析，保留TLS與固定來源限制。

- 新增[合作金庫一般美股清單](https://tcbbank.moneydj.com/w/html/stocklist.djhtm?a=US)名稱搜尋與自動收盤報價，包含來源涵蓋的AAPL、MSFT、NVDA等股票，不限VT。
- 原生網路錯誤區分HTTP／TLS／DNS／逾時，減少重複提示；不降低連線安全性。
- 支援範圍以銀行清單為準，不代表全部美股或ETF；未涵蓋標的保留手動價格。

- VT新增國泰世華盤後市價自動讀取，免登入及API Key，價格保留實際報價日期，失敗保留既有估值。
- 三個等權重按鍵維持一行三欄，長文字在按鍵內換行。

- 修正儲存交易／再記一筆未送出：移除重複提交保護包裝。
- 儲存與欄位驗證失敗顯示錯誤，保留輸入並恢復按鈕供重試；實測新增、修改與連續記帳。

- 修正帳戶名稱欄誤套操作按鈕寬度，恢復正常換行與資訊密度。
- 修正投資成本及資產摘要金額裁切；改用實際文字字形量測，保留邊緣空間並覆蓋交易、排程與統計常見金額欄。
- 以合成長名稱、大金額核對三種手機寬度、日夜、模擬放大字級、排序與金額遮罩。

- 整理全App圖示、卡片間距、字級、日曆觸控與統計／預算分頁選取狀態，改善訂閱與投資排版。
- 匯率／報價頁新增「手動股價」，投資流程新增返回；表單未儲存離開確認、儲存防連點與錯誤保留輸入。
- 同日手動股價不被自動報價覆蓋；較新日期行情仍可接續估值。背景更新保留當前篩選與位置。
- 更新說明共用安全條列格式，備份還原增加持股摘要；修正投資日曆分組及跨幣摘要顯示。

- 擴充美股ETF名稱搜尋：新增[國泰世華公開名錄](https://www.cathaybk.com.tw/cathaybk/personal/investment/etf/ranking-list/)，包含VT、VOO等來源涵蓋標的；升級後首次開啟持股設定會補更新。
- 名稱搜尋與報價分開，搜尋到名稱不代表能自動取得價格。

- 修正股票按鈕誤觸安全設定，保留App鎖且不重複驗證。
- 股票代碼／名稱搜尋後帶入資料，Android可下載台股名錄並離線快取；美股ETF名錄涵蓋國泰世華公開項目，並非完整美股清單。
- 交割欄位僅投資帳戶顯示；金額依可用寬度縮字，避免小數斷行。

- 外幣帳戶同時顯示原幣與台幣估值；換匯填入實際匯出、匯入及費用，歷史成交匯率不隨估值更新。
- 股票／ETF投資帳戶、交割帳戶、期初持倉、FIFO買賣、費稅、股利、分割／合併與損益明細。
- 買賣本金不列日常收支，現金股利列收入。交割分錄連結同一投資事件，避免重複扣款。
- 內建高精度計算機；數量、價格及匯率最多8位小數，金額保留整數分。
- Android可自動檢查盤後資料，也可手動重新整理；價格／匯率顯示日期，失敗保留上次有效值。

## 行情來源與限制

台股：[證交所](https://data.gov.tw/dataset/11549)、[櫃買中心](https://data.gov.tw/dataset/11371)。每日估值匯率：[期交所](https://data.gov.tw/dataset/11339)。依政府資料開放授權條款第1版使用並標示來源；估值匯率不是銀行實際換匯價格。

一般美股另採合作金庫公開清單，依代碼與日期匹配。既有美股ETF銀行行情來自[永豐公開頁面](https://mma.sinopac.com/StockandETF/index)，目前僅限來源回傳的熱門ETF，尚未支援任意美股代碼自動取價；VT另由[國泰世華公開詳情頁](https://www.cathaybk.com.tw/cathaybk/personal/investment/etf/details/?etfid=00991448)讀取市價；其他未涵蓋標的價格需手動設定。不要求使用者提供銀行登入或API金鑰。

交割日期暫由使用者確認，未自動推算海外假日。缺少價格或匯率時顯示待估值，不製造零價。歷史淨資產需要相應歷史估值資料。

## 日常功能

收入／支出／轉帳、付款內拆分、代墊退回、成員、日曆與列表、分類與帳戶管理、預算、固定交易與訂閱、提醒、日夜模式、安全鎖、加密備份與CSV。排程只記帳，不操作銀行。背景通知僅提醒，開啟解鎖後處理當日期數，漏掉期數需確認。

## 安裝與更新

從 [Releases](https://github.com/ting-futaba/Futaba_Money/releases/latest) 下載APK，或使用App更新中心，支援GitHub與自行設定的私人更新站。升級前另存加密備份，覆蓋安裝即可。新版可還原舊備份，含外幣／投資的新備份不適用舊版App。金額遮罩及安全鎖不等於資料庫加密。

## 驗證

141項自動測試、Android建置／lint及41項APK資源稽核通過，含外幣分錄、投資重算、備份與舊版相容。桌面隔離帳本驗證不等同A53實機；原生行情網路、通知、省電、指紋、實際觸控及最大系統字級仍需實機確認。
