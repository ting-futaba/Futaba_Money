# 雙葉帳簿 Futaba Ledger

以 Android 手機為主的離線個人帳簿。安裝檔不含使用者的帳戶、交易或預算資料。

## 最新版本：v0.5.2

- 成員管理與交易歸屬：預設自己，舊資料補齊，支援排程、備份及CSV。
- 代墊及分次收回：先列應收，收回不列收入；真正退款流程延後。
- 總覽資產遮罩與帳戶同步、日曆兩行清單、分類支出收合開關。
- 訂閱沿用自身帳戶與預設分類，輪盤第二層主分類固定原格位。

- 採用接合式索引標籤，統一卡片及標題列間距，縮小總覽摘要卡並補上線色圖例。
- 圖表選取改用形狀描邊，移除矩形焦點框；數值提示明確分隔。
- 輪盤第二層中心返回；非文字框關閉選字，減少手勢衝突。
- 開始月份影響年度衍生額度，歷史額度與舊資料保留。

- 統計分析：月、年、自訂期間與快捷範圍，收支及淨資產趨勢、分類與帳戶占比、資料提示、分類交易明細與歷期趨勢。
- 預算整合：分類獨立選跨月模式。不跨月時年度額度依開始月份與各段有效月額度計算；跨月模式分開顯示超月狀態與年度平均警告，全部不跨年。
- 保留預算設定與生效月份歷程；舊預算先確認模式，不靜默覆寫年度上限。
- 修正交易分頁滑動方向；主導覽仍不支援滑頁。輪盤三格由設定選擇，子分類返回與翻頁改單色圖示。
- 帳戶頁可顯示或隱藏金額，遮住總計、小計及個別餘額，偏好保存在本機。

## 功能與操作

收入、支出、轉帳、付款內分類拆分、代墊及收回、成員、日曆及列表、帳戶分組與月報、主子分類、分類預算、固定排程及訂閱、日夜模式、圖形與生物辨識安全鎖、加密備份及CSV匯出。

完整統計可從總覽捷徑或更多進入。中央圓形加號短按記帳、上滑開啟分類輪盤；設定位於記帳與排程內。輪盤選取只帶入表單，不會直接入帳。

預算的月額度是狀態標示基準；跨月模式以年度剩餘除以含當月的剩餘月份判斷進度警告，超月不一定需要警告。警告不阻止正常記帳。未設定額度不顯示假使用率。

固定排程只產生帳簿紀錄，不會向銀行扣款。開啟或返回App處理當日期數，錯過期數需確認。安全鎖並非資料庫加密；帳戶金額隱藏同步遮住帳戶及總覽資產；本月支出、結餘、交易及編輯仍可查看金額。

## 安裝與更新

從 [Releases](https://github.com/ting-futaba/Futaba_Money/releases/latest) 下載APK，或使用App更新中心。支援GitHub及自行設定的私人更新站。升級前另存加密備份，以新版覆蓋安裝，不必移除舊版。備份與簽署金鑰請勿公開分享。

## 驗證與限制

v0.5.2 通過93項自動測試、Android建置與lint，並檢查APK資源及資料混入。手機尺寸瀏覽器驗證不等同A53實機驗收；原生生物辨識、系統安裝器及實際觸控手感仍需實機確認。圖表以既有新台幣帳務為基準，負值退款在清單明示，圓餅比例只依正值計算。
